# 90 Day Lean

Web app/PWA para seguimiento de 90 días.

## Fechas
- Fase normal: 24/09/2026–23/10/2026
- Europa: 24/10/2026–15/11/2026
- Retorno: 16/11/2026–22/12/2026

## Publicación gratis con GitHub Pages
1. Crea una cuenta en GitHub.
2. Crea un repositorio nuevo llamado `90-day-lean`.
3. Sube `index.html`, `manifest.json` e `icon.svg`.
4. En Settings → Pages, selecciona Deploy from branch → `main` → `/ (root)` → Save.
5. GitHub te dará un enlace `https://TUUSUARIO.github.io/90-day-lean/`.
6. Ábrelo en Chrome del celular → menú ⋮ → Añadir a pantalla de inicio.

Los datos se guardan localmente en el navegador/dispositivo. No hay servidor ni sincronización entre dispositivos en esta versión.


Nueva etapa: Día 1 el 23 de noviembre de 2026 y Día 90 el 20 de febrero de 2027. Los registros empiezan limpios con una nueva clave local (v6); los datos antiguos en el navegador no se borran, pero esta versión no los carga.
